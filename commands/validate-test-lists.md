# 테스트 리스트업 검증 (단계 6b)

`persona-suite:validating-test-lists` 스킬을 실행한다. 대상: "$ARGUMENTS"

**호출 범위**: 이 커맨드는 *테스트 리스트 검증(단계 6b)만* 실행한다 — 피처 정의 기준으로 KEEP/MODIFY/DELETE/ADD(엣지 포함) 판정. 입력으로 피처 정의(요구사항 문서) + (있으면) 검증할 테스트 리스트가 필요하다.
**대상 미지정(`$ARGUMENTS` 빈 값)이면** 탐색으로 추정하지 말고 피처 정의 문서와 테스트 리스트 출처를 한 줄로 묻고 시작한다 (스킬 절차 0).
**테스트 리스트 미지정이면 모드부터 묻는다** — "핑퐁(직접 리스트업한 뒤 대조) / 판정만" 한 줄 질문으로 갈라지며, expected-behavior inventory 를 만들기 *전*에 묻는다 (스킬 절차 0). 핑퐁을 고르면 inventory 를 비공개로 선고정한 뒤 "어떤 테스트를 짤래?"를 되묻고 판정 후 공개 대조한다 (plan 의 테스트 섹션을 열기 *전*에 돌릴 것). 리스트를 지정해 부르면 게이트 없이 표준 판정으로 간다.
**다음 단계는 자동 실행하지 않는다** — 검증 후 구현(LIFECYCLE 7단계, 예: test-driven-development)으로 사용자가 직접 진행.
